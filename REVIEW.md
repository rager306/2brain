# REVIEW.md

@CODING_STANDARDS.md

This file holds this repository's review policy. Read `CODING_STANDARDS.md`
(it is included above) for the defect classes every change is checked against;
state a finding's evidence — file, line, and the behavior it breaks — and cite
the rule it violates when one applies.

Severity definitions and a "what not to flag" list are intentionally absent:
the reachable history (local commits; the GitHub PR history was not available
when this file was drafted) did not supply incidents for them. Add a severity
scale only when review history shows what this team treats as urgent, and a
do-not-flag category only when the team has declined findings of that kind
across several changes.
