## What this does not close

The legacy acceptance is still in the code, so the window is open by design. Closing it — refusing
`au.engine.*` on read — is the remaining release-2 step, and it needs the vault's own files and every
client to write the new spelling first. The vault already does; `~/.arsumbris/au-engine/` (the state
directory) and 343 scenario INPUT files still do not, which is why the acceptance stays.
