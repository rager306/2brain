## Engine swap

`swap-engine.sh` was not used: its comparison treats any shape change as a failed swap and
restores automatically, and this change is additive by design (`bridges`, `articulation_points`,
`clustering`). The runbook steps were executed by hand instead:

1. captured the five baseline reads (above);
2. installed the candidate over `/root/.2brain/bin/au` (atomic `mv`), `systemctl restart 2brain-engine`;
3. waited for `ready=true` (version counter restarted at 1);
4. re-captured the same five reads and diffed.

Result: `tb_overview`, `tb_hubs`, `tb_diagnostics` **identical**; `tb_graph_health` differs by exactly
the three new keys and the two new counts — every pre-existing value is equal; `tb_search` differs
because the pending `search` changes are now served: `total 116 → 115` (default `scope` is `own`, one
dependency hit leaves the page), and every match carries `weak` and `excerpt`, each page
`excerpt_chars`.

Live `graph_health` after the swap: 1 227 nodes, 4 730 edges, 0 broken links, **37 bridges,
57 articulation points, 3 123 triangles, transitivity 0.1816**.
